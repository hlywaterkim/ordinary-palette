# ordinary-palette assets

This branch only holds files the main branch points to or keeps out of sight:

- `docs/` — images shown in the README (swatches, curves, the cover). `scripts/update-assets.sh` on `main` regenerates the swatches and commits them here.
- `docs/social-preview.jpg` — the GitHub social preview.
- `design/` — the cover source: `cover.html` with the Figma `bg.svg` and `logo.svg`.
- `examples/preview/` — the old preview page, archived. It imported `src/` from `main`, so it does not run on its own here.

The palette itself lives on [`main`](https://github.com/hlywaterkim/ordinary-palette).
